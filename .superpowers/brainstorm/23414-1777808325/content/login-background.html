Login Screen: Background Visuals

Which visual direction should we take for the "amber waves" animated gradient background?

🌶️

Lottie Animation

Detailed, cinematic waves with floating spice particles. Matches the splash screen's high-fidelity feel.

  • Most visually impressive
  • Consistent with other screens
  • Largest file size
  • External dependency (Lottie)
〰️

Native Reanimated

Clean, performance-optimized "glow" and subtle wave effects built using React Native Reanimated.

  • Extremely performant
  • No assets to load
  • Less detailed than Lottie
  • Harder to tweak visually

SVG Path Animation

Elegant, hand-drawn look with oscillating spice-colored lines. Very lightweight and "premium artisan" feel.

  • Crisp on all screens
  • Unique brand identity
  • Requires SVG library
  • Can be complex to animate
